# 靛蓝投影讲义 · PPT 视觉设计 Skill

用于研究汇报、项目展示、产品介绍等演示文稿。白底靛蓝、微软雅黑、真实配图和清晰的阅读顺序贯穿全稿。

- [Skill 入口](skills/indigo-ppt-design/SKILL.md)
- [排版手册](skills/indigo-ppt-design/references/layout-handbook.md)，含字号、间距、图文比例、表格与流程图规则。
- [三种版式示例](skills/indigo-ppt-design/references/layout-examples.html)，下载 HTML 后用浏览器打开即可离线查看。

## 使用

将仓库中的 `skills/indigo-ppt-design` 整个目录放入本机 Codex 的个人技能目录 `~/.codex/skills/`，在新会话中调用。例如：

> 请用 $indigo-ppt-design 制作一份项目进展汇报。两组结果采用同尺度双栏对照，最后用一页流程图说明下一阶段安排。
